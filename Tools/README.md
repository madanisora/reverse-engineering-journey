# Tools Setup

| Tool | Function |
|---|---|
| radare2 | CLI disassembler & binary analysis |
| Ghidra | GUI disassembler & decompiler |
| jadx | Java/Kotlin APK decompiler |
| apktool | Decode/rebuild APK |
| frida-tools | Dynamic instrumentation |
| pwntools | CTF/exploit dev framework |

Environment: WSL2 (Ubuntu), tools installed system-wide via `apt` / `pip3 --break-system-packages`.
